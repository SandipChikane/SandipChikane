# TPO Career Cell

A polished, responsive landing page for a Training and Placement Office. The
site includes opportunity filters, role details, responsive navigation,
accessible form validation, and reduced-motion support.

## Run locally

```bash
python3 -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173).

## Verify

```bash
node --check app.js
```
